# Polymarket evaluation and dashboard

The dashboard is implemented in the [MVP's Polymarket feature](https://github.com/1nsar/investing-com/tree/main/src/features/polymarket). This folder holds the research and verification evidence.

Public REST access was verified with actual event definitions, quotes, order books and history. A read-only dashboard adds search, charts and related external news, with 10-second quote refresh. The evidence does not establish authenticated streaming, exhaustive market coverage or commercial-use permission.
